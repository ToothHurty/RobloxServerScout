# RobloxServerScout
This is a vibe coded upgrade to Vaelixx's ServerScout which looks to have been vibe coded itself.
Link to his repo here: https://github.com/Vaelixx/ServerScout

# What I added
I did not (hopefully) change anything from Vaelixx's original version of this.
His UI under the play button on a Roblox game should still work, look, and function all the same.
What I added was a movable UI in the bottom corner that lets you do everything Vaelixx's does while adding one QOL feature.
If you do not know which game a person is in, but might now which of three games (or more) a person is in, and they don't have their joins on and your not friends with them
you can put the gameId into the text box above the text box you put the players username in, and this will check if they are in any of those games.
You also have the option to just join the person immediately if you know they are in that game/one of those games.

# Set up/Installation
For set up/Installation check out Vaelixx's Repo or follow these steps (from Vaelixx's Repo, but his is cooler than mine)

RobloxServerScout works in Chrome and other Chromium-based browsers that support Manifest V3 extensions (Edge, Brave, Opera, Vivaldi).

1. Download this repository, either with Code → Download ZIP (then unzip it) or with git:
    git clone https://github.com/ToothHurty/RobloxServerScout.git
2. Open chrome://extensions (in Edge: edge://extensions).
3. Turn on Developer mode (top right).
4. Click Load unpacked and select the ServerScout folder, the one that contains manifest.json.
5. Open any Roblox game page. The panel appears under the Play button.

Updating: download the new version (or run git pull), then click the reload icon on the ServerScout card in chrome://extensions and refresh the Roblox tab.
